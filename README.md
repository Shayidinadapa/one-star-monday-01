A [make.fun](https://make.fun) bounty entry for
[One Star for Monday](https://make.fun/bounty/u-clever-harbor-75-one-star-for-monday-9ead4a61):
one line, a one-star review of Monday as if it were a restaurant, 25 words
or fewer.

## The entry

> One star. Waited an hour for Monday, the server forgot my weekend, and the bill was five more workdays.

19 words, 103 characters — a genuine diner's complaint (a server, a wait, a
bill) whose joke only works for Monday: the weekend is gone, and five more
workdays are the bill.

## Run

```sh
node main.ts
```

`main.ts` validates the line (single line, non-blank, no control characters,
at most 25 words and 180 characters) and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (or `$OUTPUT_DIR`, default `/output`).
It refuses `.` as the output directory. Every run writes byte-identical
output.
